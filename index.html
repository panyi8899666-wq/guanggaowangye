流程 / PROCESS

少一点来回 多一点共识

先回答为什么，再讨论好不好看。清晰节点，让小团队也能专业协作。

01 / DISCOVERY

理解需求

先把背景、目标、受众、使用场景与时间节点说清楚，把零散想法整理成可以执行的任务。

客户提供
需求原话、品牌与产品资料、内容清单、使用尺寸、期望时间，以及预算或制作限制。
工作室做什么
梳理目标与受众，判断信息优先级，标出资料缺口、潜在风险和合理排期。
何时确认
项目启动前，书面确认简报、工作边界、双方负责人、反馈方式与关键节点。
本步交付
结构化项目简报、任务优先级、待补资料清单与阶段时间表。
BRIEF / ALIGNMENT
02 / DIRECTION

确定方向

先用关键词、信息层级与版式骨架建立共识，再进入细节，减少方向反复。

客户提供
偏好与禁忌、竞品或参考案例，并补齐第一步标记的文案、图片和规格信息。
工作室做什么
提炼视觉关键词，建立信息层级、构图骨架与核心视觉方向，说明每项判断的依据。
何时确认
方向评审时集中反馈，确认一条主方向及其气质、构图与重点信息后再深化。
本步交付
视觉关键词、参考情绪板、版式草图、方向稿与书面确认记录。
CONCEPT / REVIEW
03 / DESIGN SYSTEM

完成系统

精修核心画面，并把字体、色彩、图形与信息规则延展到真实尺寸和应用触点。

客户提供
最终文案、高清图片、产品或活动信息、合规内容，以及确认后的实际应用尺寸。
工作室做什么
完成核心画面精修，建立可复用的视觉规则，并制作重点尺寸与应用效果。
何时确认
核心画面完成后先校对内容与视觉；重点应用呈现后，再集中确认最后一轮修改。
本步交付
定稿主视觉、常用尺寸延展、应用示意，以及字体、色彩和版式使用规则。
DESIGN / EXTENSION
04 / DELIVERY

交付落地

交付前逐项校验尺寸、出血、色彩和制作要求，让文件能被直接使用、制作与归档。

客户提供
最终制作规格、供应商刀模或模板、文件接收方式，以及需要保留的版本与命名要求。
工作室做什么
完成印前与屏幕输出检查，整理源文件、链接素材、字体说明和各用途输出文件。
何时确认
最终导出前确认校样、文件清单与使用范围；涉及实体制作时再核对生产规格。
本步交付
约定范围内的源文件、PDF／JPG／PNG 输出、版本清单、命名规范与归档说明。

合作答疑 / FAQ

合作前 先把话说清楚

价格、边界与协作方式先说明，咨询时直接讨论真正的问题。

包含合作期内已确认优先级内的广告主画面、品牌日常延展、常用尺寸适配、文件整理与进度同步。实体制作、印刷、搭建、摄影、第三方素材授权及超出已排计划的新任务不包含在设计服务内；如需制作，将按规格、数量、材质与工艺另计。

由同一位设计负责人直接理解需求、做出判断并跟进交付，沟通链路更短，长期视觉也更容易保持一致。适合希望稳定协作、重视执行细节，同时不需要大型团队层层配置的客户。

先整理需求与当月优先级，再确认视觉方向；方向通过后进入系统设计与尺寸延展，最终按用途完成文件校验、输出和归档。每一步都设置书面确认节点，减少后期返工。

启动时会依据任务数量、资料完整度、应用尺寸与确认节点排出当月计划。具体日期在简报确认后书面约定；如遇新增、加急或反馈延迟，会同步调整优先级与交付时间。

采用阶段性集中反馈：先确认方向，再处理细节与尺寸延展。已确认方向后的新增需求、内容大改或临时尺寸，不混入当前节点反复修改，而是重新评估工作量并排入当月计划。

正式合作会在协议中明确源文件交付范围、商用授权方式及作品公开规则。本站案例均为实际项目，画面与说明按真实交付内容呈现。
